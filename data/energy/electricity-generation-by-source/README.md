## Parse notes (T04)

- Long format: **one observation per fuel × quarter**.
- `notes` = `fuel=<ExactFuelLabel>` (trailing Excel spaces stripped).
- `[x]` → `value` empty / null, `observation_status=missing`.
- Column headers with `[provisional]` → `observation_status=provisional` (currently Q2 2026 only in this pin).
- **Annual sheet not ingested** (optional later; quarterly is the authoritative grain for this indicator).
- MPP-only and Other-generators blocks are **not** curated (would duplicate UK totals without a generator dimension).

4. Asset URLs on GOV.UK change each release — always pin checksummed raw.
