# `web/src/brand` — British Exchange UI kit (v1)

"One ink, drawn by instruments." Read [`docs/visual-identity.md`](../../../docs/visual-identity.md) first.

**One import:** `import { … } from "@/brand"` (`index.ts`). It exports the canonical kit only.

| Path | Role |
|------|------|
| `index.ts` | The barrel: root, plates, template, menus, motion, charts, data helpers |
| `brand.css` | Tokens and utilities under `.bo` (colour, type, grid, screen tints, plates, panels) |
| `fonts.ts` | Libre Caslon Display, Geist, Geist Mono, Archivo (condensed) via `next/font` |
| `BrandRoot.tsx` | Wraps a page: applies `.bo` + fonts |
| `Plate.tsx` | Halftone plate component + `PLATES`, `REF_ICON_PLATES` (rail photos), `ICON_PLATES`, `SCENE_ICON_PLATES` |
| **`template/`** | **The canonical sector page.** `SectorPage` (mast · hero plate · name on an ink strip · optional stats · threshold slot) and `Explorer` (photo-plate rail + instrument-frame canvas), plus `PlateBand` / `FieldBand` |
| `PrintSelect.tsx` | Brand menu on Base UI (`@base-ui/react`); used through `MenuControl` / `PeriodControl` |
| `motion/` | `DualScramble` (+ `ScrambleGroup`), `HalftoneMotion`, `DitherField` (+ fields), `DensityStrip`, `groundField` — see the exchange-motion skill |
| `instrument/` | `TimeChart` (line, bars, stack; keyboard inspection; empty frame when no points) and `RankBars` |
| `housing/` | Housing & Land, the first sector on the template: `HousingPage` (a `SectorPage`), `canvas/HousingExplorer` (an `Explorer`), loader, atlas, and sector-only stages (maps, Price Paid, affordability, stock) |
| `sector/`, `charts/` | v0.2 legacy — not exported; retire as sectors move to v1 |
| `ui/InstrumentSelect`, `motion/FlickerFigure` | Lab experiments — not part of the template |

## New sector page (the template)

```tsx
// app/<sector>/page.tsx (server) → <BrandRoot><Suspense><MySectorPage data={…} /></Suspense></BrandRoot>
"use client";
import {
  SectorPage, Explorer, ExplorerHead, FigureStrip, ControlRow, MenuControl, PeriodControl, ResetButton,
  Stage, SourceLine, EmptyStage, TimeChart, REF_ICON_PLATES,
} from "@/brand";

<SectorPage name="Energy" label="Energy & Industry" plate={{ name: "coolingTowers" }}>
  <Explorer sector="Energy & Industry" indexLabel="Energy index"
            domains={DOMAINS /* {id,title,question,plate:{src},status} */}
            active={domain} onSelectDomain={setDomain}>
    <ExplorerHead views={VIEWS[domain]} view={view} onView={setView} />
    <FigureStrip figures={figures} />
    <ControlRow>
      <MenuControl label="Measure" value={measure} options={MEASURES} onChange={setMeasure} />
      <PeriodControl years={years} from={from} to={to} onChange={setPeriod} />
      {adjusted && <ResetButton onClick={reset} />}
    </ControlRow>
    <Stage title="Electricity generated by source" meta="1996–2025 · UK · annual"
           foot={<SourceLine sources={sources} />}>
      {ready ? <TimeChart … /> : <EmptyStage label="In preparation">Ready series appear once validated.</EmptyStage>}
    </Stage>
  </Explorer>
</SectorPage>
```

- The sector owns data, URL state and any special stage (maps, calculators). The template owns layout, rhythm and motion.
- Every domain uses the same order: head, then figures, then controls, then stage, then coverage. Every stage state fills the frame.
- Locked with Housing: chosen tabs and chips are solid ink with paper type; hover is that same solid ink block; focus is Signal. Ranked bars are solid ink. Do not add a palette, a tab shape, or a chart style. A custom instrument stays inside `Stage`. See `docs/visual-identity.md` → “A new sector (locked)”.
- Motion comes built in: the rail condenses, one ink carriage travels between tabs and rail rows, plates magnify under a loupe, labels dual-scramble on hover, and figures scramble when they change. Reduced motion makes all of it instant.
- Keep URL updates client-side (`history.replaceState`) unless the server must send new data. See `HousingExplorer.setQuery`.

## Using a plate

```tsx
import { Plate } from "@/brand/Plate";

<Plate name="coolingTowers" treatment="print" position="50% 40%" style={{ minHeight: 640 }}>
  <div className="bo-panel">…copy on a solid panel…</div>
</Plate>
```

New plates come from `.claude/skills/observatory-imprint/scripts/halftone-plates.py` (`--bare --mask`), then get a `PLATES` entry. Data-generated plates need a `source`.

## Any other page

1. Wrap in `<BrandRoot>`.
2. Pick a mode per section: Quiet, Monumental (max one), Index.
3. Headlines `.bo-d1–3` (Caslon, sentence case), figures `.bo-fig`, labels `.bo-label`.
4. No parallel palettes, no opacity tints, no Signal on text.
